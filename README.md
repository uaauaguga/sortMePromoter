# sortMePromoter

## Introduction
- sortMePromoter is a tool for bacteria promoter prediction. It is simply a 5-layer 1-D resnet training on upstream 50mer of TSS in diverse bacteria identified by differential RNA-seq (dRNA-seq)
- sortMePromoter dependes on pytorch

## Usage

```bash
scripts/sortMePromoter.py --fasta examples/RF00174-Cobalamin-U75-D25.fa --output examples/RF00174-Cobalamin-U75-D25.bed
```
